## ❓ Frequently Asked Questions

### "Do I need coding skills?"
**No!** Basic computer skills are enough. If you can edit a Word document and follow instructions, you can customize this.

### "Will this work on mobile?"
**Yes!** It's mobile-first design. Most customers will likely use it on their phones.

### "Can customers pay online?"
**Not by default.** This tracks orders but doesn't process payments. You can:
- Add payment links manually (Venmo, CashApp, etc.)
- Collect payment at pickup
- Upgrade to add Stripe/Square ($500 add-on)

### "What if I get too many orders?"
The system handles hundreds of orders fine. If you grow beyond that, we offer backend upgrade.

### "Can I use my own domain?"
**Yes!** Like www.yourbusiness.com. Costs ~$12/year for the domain name.

### "Is my data secure?"
Yes, with built-in security features. Data stored in browser localStorage. For ultra-sensitive data, consider backend upgrade.

### "Can multiple people use the owner dashboard?"
Everyone uses the same password. For multiple accounts with permissions, consider team upgrade ($600).

### "What if I need help?"
Email support included! Plus comprehensive documentation and video tutorials.

### "Can I sell this to my friends who own businesses?"
**No**, that violates the license. But we offer reseller partnerships! Contact us.

### "Will you update it?"
Yes! Security updates and bug fixes included. Major feature updates available separately.
